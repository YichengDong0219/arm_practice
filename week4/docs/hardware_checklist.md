# 实机前检查清单

## 环境

- [ ] 激活包含 `numpy`、`pyserial`、`matplotlib` 的 Python 环境。
- [ ] `python -c "import numpy, serial, matplotlib"` 无报错。
- [ ] 在设备管理器确认实际 COM 口；不要机械照抄 COM5 或 COM6。
- [ ] 先运行 1.9、1.10 的默认预演，确认帧数分别为 180 和 160。

## 机械与电气

- [ ] 机械臂接独立稳压电源，控制板与舵机公共地可靠。
- [ ] USB-to-UART 接线正确，DTR/RTS 保持关闭。
- [ ] 机械臂真实姿态接近软件假定的全零位。
- [ ] 清空机械臂运动范围，准备随时断电。
- [ ] 核对 J6 正负方向；先用 5° 到 10° 小幅动作测试夹爪。
- [ ] 核对指导书接口图：STM32 接口 3~8 分别对应 J6、J2、J5、J4、J3、J1。

## 推荐验收顺序

1. 实验 1.8：只运行矩阵计算，结果应接近位置 `[2.3991, 2.3991, 1.1]`。
2. 实验 1.9：先单独测试 J1，再测试 J3，再测试 J6，最后运行多轴联动。
3. 实验 1.10：先不放物体测试路径；再降低夹爪幅度测试；最后进行实际抓取。
4. 任一方向不符、碰撞趋势、堵转或电源复位时立即停止，不直接尝试完整序列。
