## 缺失或必须现场确认

| 项目 | 当前状态 | 影响 |
| --- | --- | --- |
| `animator_3d.py` | 指导书只给接口说明，工作区无完整实现 | 只影响 1.8 选做动画，不影响必做矩阵解算 |
| `airplane_geometry.py` | 工作区无文件 | 只影响动画模型显示 |
| Python 依赖 | 当前默认 Python 是 MSYS2 3.12.11，缺少 NumPy | 必须激活 `ra_class` 或新建虚拟环境 |
| 串口号 | 指导书 1.9 写 COM5、1.10 写 COM6，现有代码多用 COM5 | 必须以设备管理器为准，通过 `--port` 传入 |
| 真实零位与舵机正方向 | 无反馈协议，代码无法自动识别 | 实机前必须小角度逐轴标定 |
| 抓取物、抓取位和目标位 | 指导书只给一组示例角度 | 1.10 必须按桌面布局重新确认，不能盲目照抄 |
| 实机结果 | 当前没有本周照片、视频、角度记录 | 仍需完成硬件验收与实验报告证据采集 |

## 代码覆盖结论

- 1.8：有完整必做代码，运行后应得到末端位置 `[2.3991, 2.3991, 1.1]`；动画代码也给了调用方式，但动画模块本体缺失。
- 1.9：有完整代码，底层协议和插值无需重写；主要工作是串口、方向和分阶段实机验证。
- 1.10：有完整动作序列代码；主要新增工作不是编程，而是抓取位标定、碰撞检查、夹爪力度/方向确认和结果记录。
